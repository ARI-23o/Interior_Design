# SOWAKAAH™ Interior Design Studio

A high-converting, luxury interior design studio web application built with **React, TypeScript, and Tailwind CSS**.

## 🌟 Key Features

- **Luxury Visual Identity**: Balanced editorial aesthetic with warm neutrals, dark charcoal typography, and bronze accents.
- **Conversion-Optimized Hero**: Headline and dual CTAs with instant trust metrics.
- **Dynamic Portfolio & Case Studies**: Clickable project case studies detailing client briefs, architectural approaches, material palettes, and galleries.
- **Interactive Before $\rightarrow$ After Slider**: Real-time touch/mouse drag comparison slider.
- **5-Stage Execution Process**: Structured transparency from initial consultation to key handover.
- **Multi-Step Budget Qualification Engine**: Interactive estimator for 1/2/3 BHK, Villas, and commercial spaces.
- **Smart WhatsApp Widget**: Context-aware triggers with pre-filled inquiries.
- **SEO-Optimized Content**: Educational guides and localized landing structures.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ARI-23o/Interior_Design.git

# Navigate to project directory
cd Interior_Design

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```
